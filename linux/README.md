# Linux edition / Edición Linux

## English

The Linux edition is a single Bash script: [`portable-file-organizer.sh`](portable-file-organizer.sh).

Requirements:
- Bash 4+
- `base64`
- `awk`
- `date`
- `mv`
- `mkdir`
- `rmdir`
- `tr`

Run it with:

```bash
chmod +x portable-file-organizer.sh
./portable-file-organizer.sh
```

It has been designed for mainstream GNU/Linux distributions and keeps Undo metadata inside `_PortableFileOrganizer`.

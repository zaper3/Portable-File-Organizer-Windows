# Portable File Organizer for Windows v3.1

Primera versión pública preparada para distribución.

## Destacados

- Organización portable mediante un único archivo `.bat`.
- No requiere instalación.
- Funcionamiento local/offline.
- Clasificación por categorías principales.
- Subclasificación opcional por formato, fecha y reglas simples basadas en nombre.
- Protección frente a sobrescrituras.
- Exclusión de descargas temporales/incompletas.
- Undo transaccional de la última organización.
- Registros internos agrupados en la carpeta `_Organizador`.
- Migración automática de registros procedentes de v3.0.

## Uso rápido

1. Descarga y extrae el paquete de la Release.
2. Copia `Organizar_Archivos_Portable.bat` dentro de la carpeta que quieras organizar.
3. Ejecuta el archivo.
4. Selecciona `1 - Organizar archivos` o `2 - Deshacer ultima organizacion`.

## Seguridad

El programa no utiliza Internet, servicios remotos ni telemetría. Antes de usarlo con datos críticos, prueba primero el comportamiento en una carpeta temporal y conserva copias de seguridad independientes.

## Integridad

Publica junto a la Release el archivo `.sha256` correspondiente al ZIP para que los usuarios puedan verificar la integridad de la descarga.

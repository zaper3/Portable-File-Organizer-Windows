## English

### What is it?

Portable File Organizer for Windows is a lightweight, offline Windows utility distributed as a single `.bat` file. Copy it into any folder, run it, and organize the files located directly in that folder without installing software or running a background service.

### Highlights in v3.1

- Portable single-file execution.
- Main categorization by file type.
- Optional organization by format, date and simple intelligent file-name rules.
- Safe duplicate handling: existing files are never overwritten.
- Transactional Undo for the latest compatible organization run.
- Internal Undo/history records stored inside `_Organizador` instead of cluttering the organized folder root.
- Automatic migration of compatible v3.0 Undo records.
- Local/offline operation with no intentional telemetry or file-name uploads.

### Recommended download

Download the attached ZIP package and extract:

`Organizar_Archivos_Portable.bat`

Place the file inside the folder you want to organize and double-click it.

### Integrity verification

A SHA-256 checksum file is provided with the Release when available. Use it to verify the integrity of the downloaded package.

### Important

Before using any file-moving utility on critical information, test it in a temporary folder and maintain appropriate backups.

## Español

### ¿Qué es?

Portable File Organizer for Windows es una utilidad ligera y sin conexión para Windows distribuida como un único archivo `.bat`. Puedes copiarla dentro de cualquier carpeta, ejecutarla y organizar los archivos situados directamente en esa carpeta sin instalar software ni mantener servicios en segundo plano.

### Novedades y características de v3.1

- Ejecución portátil desde un único archivo.
- Categorización principal por tipo de archivo.
- Organización opcional por formato, fecha y reglas inteligentes simples basadas en nombres de archivo.
- Gestión segura de duplicados: nunca sobrescribe archivos existentes.
- Undo/deshacer transaccional de la última ejecución compatible.
- Registros internos de Undo e historial almacenados dentro de `_Organizador`, evitando ensuciar la raíz de la carpeta organizada.
- Migración automática de registros compatibles generados por v3.0.
- Funcionamiento local/offline sin telemetría ni envío intencionado de nombres de archivo.

### Descarga recomendada

Descarga el paquete ZIP adjunto y extrae:

`Organizar_Archivos_Portable.bat`

Coloca el archivo dentro de la carpeta que quieras organizar y haz doble clic sobre él.

### Verificación de integridad

Cuando esté disponible, la Release incluye un archivo con el checksum SHA-256. Puedes utilizarlo para verificar la integridad del paquete descargado.

### Importante

Antes de utilizar cualquier herramienta que mueva archivos sobre información crítica, pruébala primero en una carpeta temporal y mantén copias de seguridad adecuadas.

# Changelog / Historial de cambios

All notable changes to this project will be documented in this file. / Todos los cambios relevantes del proyecto se documentarán en este archivo.

---

## [3.1] - 2026-08-13

### English

#### Added
- Internal `_Organizador` folder to store Undo records without cluttering the organized folder root.
- Automatic migration of records generated by v3.0.
- Preservation of history required to undo compatible previous runs.

#### Improved
- Internal metadata organization.
- User experience and visual cleanliness of the main folder.

### Español

#### Añadido
- Carpeta interna `_Organizador` para almacenar los registros de Undo sin ensuciar la raíz de la carpeta organizada.
- Migración automática de los registros generados por v3.0.
- Conservación del historial necesario para deshacer operaciones anteriores compatibles.

#### Mejorado
- Organización de metadatos internos.
- Experiencia de uso y limpieza visual de la carpeta principal.

---

## [3.0] - 2026-08-13

### English

#### Added
- Transactional Undo for the latest organization run.
- Unique identifier for each run.
- Independent logs for movements, created folders and executions.
- Conservative restoration: existing files are never overwritten.
- Removal only of folders created by the organizer and only when they are empty.
- Support for retrying a partial Undo after resolving conflicts.

### Español

#### Añadido
- Undo transaccional de la última organización.
- Identificador único por ejecución.
- Registro independiente de movimientos, carpetas creadas y ejecuciones.
- Restauración conservadora: nunca sobrescribe archivos existentes.
- Eliminación exclusiva de carpetas creadas por el organizador y únicamente cuando están vacías.
- Soporte para reintentar un Undo parcial después de resolver conflictos.

## [2.2] - 2026-08-13

### English

#### Fixed
- UTF-8 encoding without BOM for correct `cmd.exe` compatibility.
- CRLF line endings for Windows.
- Simplified PowerShell launcher without problematic `^` continuations.

### Español

#### Corregido
- Codificación UTF-8 sin BOM para compatibilidad correcta con `cmd.exe`.
- Finales de línea CRLF para Windows.
- Lanzador PowerShell simplificado sin continuaciones problemáticas mediante `^`.

## [1.0] - 2026-08-13

### English

#### Added
- Portable file classification through a single `.bat` file.
- Main categories based on file extensions.
- Overwrite protection.
- Exclusion of temporary and incomplete downloads.
- Basic movement log.

### Español

#### Añadido
- Clasificación portable de archivos mediante un único `.bat`.
- Categorías principales por extensión.
- Protección contra sobrescritura.
- Exclusión de archivos temporales e incompletos.
- Registro básico de movimientos.

# Windows edition / Edición Windows

## English

The Windows edition is implemented as a single portable `.bat` file with an embedded PowerShell block. It targets Windows 10/11 and requires no installation or administrator privileges when used in folders where the current user already has write permission.

Repository source: [`../Organizar_Archivos_Portable.bat`](../Organizar_Archivos_Portable.bat)

The official Release package uses the neutral filename:

```text
portable-file-organizer-windows.bat
```

## Español

La edición Windows está implementada como un único archivo `.bat` portable con un bloque PowerShell embebido. Está orientada a Windows 10/11 y no requiere instalación ni privilegios de administrador cuando se utiliza en carpetas donde el usuario actual ya tiene permisos de escritura.

Código fuente en el repositorio: [`../Organizar_Archivos_Portable.bat`](../Organizar_Archivos_Portable.bat)

El paquete oficial de la Release utiliza el nombre neutral:

```text
portable-file-organizer-windows.bat
```
